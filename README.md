# visionOS Vehicle Demo Skill

A reusable Codex Skill for turning a user-supplied vehicle model into an interactive Apple Vision Pro experience.

## Features

- Blender model normalization
- Semantic entity hierarchy
- Mixed-reality miniature vehicle
- 1:1 immersive cockpit
- Gaze and pinch interactions
- Spatial audio
- Vehicle startup sequences
- Simulator and device validation

## Installation

Ask Codex:

> Install this skill:
> https://github.com/bibabo-dev/visionos-vehicle-demo-skill/tree/main/skills/build-visionos-vehicle-demo

## Usage

Start a new Codex task and say:

> Use $build-visionos-vehicle-demo to turn my vehicle model into an Apple Vision Pro experience.

## Asset policy

No third-party vehicle models, photographs, music, or HDRI files are included. Users must supply assets they have permission to use.
